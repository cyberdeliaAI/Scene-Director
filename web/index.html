Settings

Server

In LM Studio, open the Developer tab and start the server. Any OpenAI-compatible server works under Other.

Needed when your server requires authentication, such as an LM Studio API token. Save stores it on this computer in settings.json next to the app. It is never shown in this page again.

This model writes the prompts. Automatic uses the model loaded in LM Studio. A non-thinking model is fastest.

Each run becomes a .txt file with one prompt per line.

Generation settings

These choices control the language model that writes your prompts. Save applies them to future runs. Model and server support can vary.

0–2. Higher values allow more variation.

Greater than 0, up to 1.

1–1000. Limits the next-token candidate pool.

−2 to 2. Positive values discourage reuse.

More reasoning can take longer. Supported levels depend on the model.

Some local models use this switch. Server default leaves it unset.

Only these generation controls are editable. Prompts, token limits and arbitrary API fields are not settings. If the server rejects optional controls, the app retries without those controls and shows a notice.

Shared prompt presets

Use the same UTF-8 .txt files as Cyberdelia Prompt Engineer. Enter the full path, or use Choose folder in the desktop app. Files are read directly; nothing is copied into or written to these folders. Leave empty for built-in presets only.

Selecting a folder fills its path. Press Save to apply it; Cancel keeps your saved settings.

Direct .txt children, up to 64 KB each. After Save, use Refresh presets or select a file again to load its latest content. Changing a file does not replace instructions already shown in your brief.
